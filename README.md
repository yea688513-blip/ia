# Repositorio IA

Este repositorio contiene los talleres, proyectos y ejercicios desarrollados a lo largo de las semanas de formación en Inteligencia Artificial y programación.

## Estructura del Repositorio

- **`primeraSemana/`**: Algoritmos y lógica inicial (pseudocódigo en PSeInt: `ordenar.psc`).
- **`segundaSemana/`**: Documentación y borradores de proyectos formativos (`riwi-tres-cupos-borrador.txt`).
- **`terceraSemana/`**: Proyectos prácticos implementados con IA (`PROYECTO TESLA CODE REALIZADO CON IA.txt`).
